# 🏥 Hospital Admissions Dashboard | Power BI

---
## 📌 Overview

Developed an interactive Power BI dashboard to analyze hospital admissions, patient demographics, wait times, satisfaction scores, and department referrals. The dashboard provides insights that can support healthcare operations and service improvement.

## 🎯 Key Insights

* Total Patients: 9216
* Average Admission Rate: 0.50
* Average Satisfaction Score: 1.36
* Average Wait Time: 35.26 mins
* Department referral trends analyzed

---
## 📈 Features

* Quarterly filtering
* Patient trend analysis by month
* Race-wise patient distribution
* Department referral breakdown
* Demographic analysis by age, gender, and race
* KPI cards for operational metrics

---
## 🛠 Tools Used

* Power BI
* DAX
* Power Query
* Data Visualization
* Data Analysis

---
## 🚀 How to Use

1. Download the `.pbix` file
2. Open in Power BI Desktop
3. Explore visuals and interact with filters
